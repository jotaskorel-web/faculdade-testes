#execerciocio vetores
1-Faça um programa que crie um vetor de no máximo 100 elementos. Que leia um tl e que leia este vetor, e um numero, e diga quantas vezes este numero se encontra no vetor. (ex1vetores)

2-Faça um programa que leia um vetor de no máximo 50 elementos do tipo float, e um tl, e que encontre o menor e o maior valor do vetor. (ex2vetores)

3- Faça um programa que leia um vetor de no máximo 100 elementos do tipo double, e um tl, e que encontre a média dos valores do vetor lido e que imprima os valores que são menores que a média (ex3vetores)

#exercicios agregados homogeneos 2
4-Faça um programa em C que leia os elementos de dois vetores de inteiros, cujos tamanhos lógicos (TLs) são conhecidos, e construa um terceiro vetor contendo apenas os elementos que aparecem em ambos os vetores.

     No exercício 4 não se leva em consideração se um elemento em comum entre conj1 e conj2 já está inserido em conj3, ou seja, se

conj1 = [3,4,6] e conj2 = [3,7,4,3]
     então, conj3 será [3,4], onde o elemento 3 está repetido.
    Refaça este exercício, mas que o mesmo seja capaz de evitar a duplicidade de  elementos em conj3

6-      Faça um programa em linguagem C que seja capaz de fazer a soma de dois vetores de dimensões N. Os valores dos dois vetores, bem como os do vetor resultado devem ser armazenados em conjuntos. Os vetores têm no máximo 50 coeficientes.

7-     Um armazém comercializa 100 diferentes mercadorias, identificadas por números inteiros de 1 a 100. A quantidade de mercadorias em estoque e o preço de cada mercadoria devem ser armazenadas em conjuntos distintos. Ao fim de cada dia de trabalho, o comerciante fornece um conjunto com o total de cada mercadoria que foi vendida. Faça um algoritmo que seja capaz de:

a- conhecer os valores de cada conjunto;

b- calcular e informar a situação do estoque do comerciante ao fim do dia para cada mercadoria;

c- calcular e informar o faturamento do dia com a venda das mercadorias.

8-      Faça um algoritmo que receba como entrada dois conjuntos de elementos inteiros e seus respectivos tamanhos lógicos, com no máximo 100 elementos cada um, que seja capaz construir um terceiro conjunto que contenha a união dos elementos entre os dois conjuntos dados. No conjunto união não poderá existir elementos repetidos.
